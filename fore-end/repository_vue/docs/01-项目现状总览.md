## 4. 当前前端页面能力

页面目前有 3 个模式：

- `普通对话`
- `固定文档`
- `向量知识库`

页面可以展示：

- 用户问题
- 模型回复
- 是否命中知识库
- 引用来源
- 片段分数（仅向量知识库模式）

## 5. 当前已验证通过的内容

### 普通对话

已验证前端能调用后端 `/api/ai/chat`，后端能调用 Ollama `/api/chat` 返回结果。

### 固定文档 RAG

已验证 `knowledge` 目录中的 Markdown 文档可以被读取，并能通过问题命中唯一标记，例如：

```text
RAG-CHECK-20260430-ALPHA
```

这说明：

- 目录配置生效
- 文档读取生效
- Prompt 拼接生效
- 引用来源展示生效

## 6. 当前正在推进的内容

### 向量知识库

已经实现了第二阶段的基础思路：

1. 读取 `knowledge` 目录文档
2. 文档切块
3. 调用 `/api/embed`
4. 计算相似度
5. 选取 `topK` 片段
6. 再调用 `/api/chat` 生成回答

但目前这条链路还没有稳定通过，需要继续排查后端运行时异常。
