# 接口与页面说明

## 1. 前端页面入口

当前前端是一个 Vite + Vue 3 页面，支持 3 种工作模式：

- `普通对话`
- `固定文档`
- `向量知识库`

开发环境通过 Vite 代理把 `/api` 请求转发到：

```text
http://127.0.0.1:8080
```

## 2. 当前前端调用接口

### 2.1 普通对话

```text
POST /api/ai/chat
```

请求体：

```json
{
  "question": "请解释一下 Spring Boot 如何调用 Ollama。"
}
```

返回体：

```json
{
  "answer": "..."
}
```

### 2.2 固定文档知识库

```text
POST /api/ai/rag-simple
```

请求体：

```json
{
  "question": "知识库验证口令是什么？"
}
```

返回体：

```json
{
  "answer": "...",
  "sources": [
    {
      "fileName": "知识库标记.md",
      "snippet": "...",
      "score": null
    }
  ],
  "knowledgeHit": true
}
```

### 2.3 向量知识库

```text
POST /api/ai/rag
```

请求体：

```json
{
  "question": "知识库方案里第二阶段推荐做什么？"
}
```

返回体结构和 `rag-simple` 相同，但 `sources[].score` 应该会有数值。

### 2.4 知识库状态总览

```text
GET /api/ai/knowledge
```

用途：

- 查看当前知识库目录
- 查看命中的文件列表
- 查看哪些文件会进入固定文档模式
- 查看哪些文件会进入向量模式以及各自 chunk 数

### 2.5 重建向量索引

```text
POST /api/ai/knowledge/reindex
```

用途：

- 清空当前内存中的向量缓存
- 立即按当前配置重新扫描并重建 chunk embedding
- 用于配置调整、文档变更后的快速验证

## 3. 后端职责拆分

### 3.1 `/api/ai/chat`

后端直接调用 Ollama：

```text
POST http://127.0.0.1:11434/api/chat
```

### 3.2 `/api/ai/rag-simple`

后端做的事：

1. 读取 `knowledge` 目录中的 `.md`
2. 把文档内容直接拼接进 Prompt
3. 调用 `/api/chat`
4. 返回答案和来源

### 3.3 `/api/ai/rag`

后端做的事：

1. 读取 `knowledge` 目录中的 `.md`
2. 按配置切块
3. 对问题调用 `/api/embed`
4. 对文档 chunk 做 embedding
5. 计算相似度
6. 取 topK 命中片段
7. 调用 `/api/chat`
8. 返回答案和来源

## 4. 前端页面当前表现

### 普通对话模式

- 不读取知识库
- 不显示知识库命中状态
- 不显示来源片段

### 固定文档模式

- 读取整个知识库目录
- 直接把文档拼进 Prompt
- 能显示命中来源
- 适合验证知识库是否接通

### 向量知识库模式

- 先做 embedding 检索
- 来源里应显示 `score`
- 适合做更接近正式系统的检索增强问答
- 当前仍在排障中

### 知识库状态面板

- 可直接看到当前扫描目录和匹配规则
- 可看到每个文件的大小、修改时间、chunk 数
- 可手动刷新知识库状态
- 可手动触发“重建向量索引”

## 5. 当前配置项

当前已知关键配置：

```properties
ollama.base-url=http://127.0.0.1:11434
ollama.chat-model=deepseek-r1:7b
ollama.embedding-model=bge-m3:latest
knowledge.simple.base-dir=P:/AIprogect/repository/fore-end/repository_vue/knowledge
knowledge.simple.file-pattern=*.md
knowledge.vector.top-k=4
knowledge.vector.chunk-size=900
knowledge.vector.chunk-overlap=150
knowledge.vector.max-files=12
knowledge.vector.max-chunks=120
```

如果修改这些配置，必须重启后端服务。
